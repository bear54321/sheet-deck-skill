# 實物照片轉 3D（以館藏地球儀為例）

## 拍照（iPhone 內建相機即可）

- 用 **1×** 鏡頭（不要 0.5× 超廣角），一般照片模式，關閃光燈，長按畫面鎖定對焦與曝光。
- 人繞著物件走，**不要轉動物件**。拍三圈：斜上方、平視、蹲低略往上，每圈 20–30 張，相鄰兩張重疊一半以上，共 60–100 張。
- 遠近大致一致即可；想要更清楚的區域，三圈拍完再靠近補拍。
- 避開燈管反光（反光會被烤進貼圖）；被桌子或底座擋住的部位不用勉強拍。
- 用 AirDrop（選項 → 所有照片資料）傳到 Mac，放進一個資料夾。

## 建模（Mac 內建 Object Capture，免費、不上傳）

需要 Apple 晶片的 Mac。

```bash
swiftc -O scripts/object_capture.swift -o capture
./capture <照片資料夾> <輸出資料夾>/ full     # 也可用 medium
```

輸出資料夾會有 OBJ、USDA 與 8K 貼圖（`*_tex0.png`）。8 GB 記憶體、58 張照片的 full 品質約 8 分鐘。

Windows 替代方案：RealityScan（需 NVIDIA 顯示卡）、Meshroom（免費、需 NVIDIA）、Agisoft Metashape（付費）。

## 規則形狀可以再「修正」

攝影測量的貼圖是很多零碎小塊，表面也會凹凸。若物件是規則形狀（球、圓柱），可以在 Blender：

1. 匯入掃描的 OBJ，用最小平方法擬合出球心與半徑（地球儀實例誤差只有 0.2%）。
2. 建一顆 UV 球（256×128 段），用 Cycles 的 **Bake → Diffuse（只要 Color）**、Selected to Active，把掃描貼圖烘到球上（8192×4096，cage extrusion 約半徑的 5%）。
3. 被底座擋住、拍不到的區域會是黑的，用附近顏色填滿。
4. 底座等配件另外建簡單幾何，設單色材質。
5. 匯出 GLB（JPEG 貼圖），再 `glb2js.py`。

結果：一張完整的 8K 等距長方形貼圖，放大後小地名也讀得到，模型只有 4.8 MB。
