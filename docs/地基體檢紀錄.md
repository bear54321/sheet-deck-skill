### 體檢時的其他發現

- 用字串代替型別（新增頁來源 `'live:'`／`'pdf:'`／`'doc:'`）：之後在寫法整理中統一成 `pageFrom()`／`parseFrom()`（`add51b1`，見 `docs/寫法整理紀錄.md`）。
- 寫死的色碼（CSS 255 個、JS 198 個）：大多是各風格自己的配色，哪些違反「用 `--th-*`」規則**不確定**，沒有處理。

### 不做

- 把 template 拆成多個 JS 檔或加建置流程：會破壞「單一 HTML、雙擊就能開、匯出就能帶走」的核心設計。
- 導入 ESLint、TypeScript：要新增 package.json 和工具鏈，對單檔範本成本太高；改用 Python 檢查腳本。
- 規則禁止寫死色碼：會擋到各風格正當的配色，留給人工判斷。
